# Ventra-EMS pre-release channel

Home Assistant add-on repository for Ventra-EMS release candidates, used on internal test
systems before a public release. Not meant for production installations.

The add-on images are private: a Home Assistant system needs a registry login for `ghcr.io`
(Settings → Add-ons → Add-on store → ⋮ → Registries) with a token that may read the packages.

This repository is written by the "Pre-release" workflow; don't edit it by hand.
